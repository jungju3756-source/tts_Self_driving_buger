## 1. 음성 — B 버튼 → 상시 듣기 (`rapa1/voice_ptt.py`)

```
 마이크 상시 열림 (arecord 16 kHz, 0.1 s 단위)
   └─ RMS 가 주변 소음 × 3 (최소 400) 이상 0.3 s 연속 → 말 시작 (직전 0.3 s 포함)
   └─ 0.6 s 조용 → 말 끝   ·  0.5 s 미만 / 6 s 초과는 Gemini 에 안 보내고 버림
   └─ Gemini 받아쓰기 (gemini-3.5-flash-lite REST) → intent.parse_strict
         "N번 + 이동 동사"  → Nav2 이동         ("1번으로 가", "3번 이동해", "이 번으로 가줘")
         "멈춰/정지/그만"   → 모든 Nav2 목표 취소 + 0 명령 (웹·RViz 에서 보낸 목표도)
         그 외              → 조용히 무시 (부저 없음, 웹 기록 칸에 회색으로)
   └─ 주행 중에는 "멈춰" 만 받음 (Nav2 action status 구독 → 웹에서 보낸 주행도 포함)
```
- **B 누르고 말하기는 그대로 백업으로 남음** (B 로 한 말은 기존 `parse_command` 규칙)
- 상시 듣기 프롬프트에는 장소 이름을 **넣지 않음** — 넣으면 잡음을 "1번으로 가" 로 지어낼 수 있어서
- 부저 직후 0.8 s 는 말 시작 감지 안 함 (자기 부저 소리 무시)
- 조정 파라미터: `vad_ratio`(3.0), `vad_min_rms`(400), `vad_start_chunks`(3), `vad_end_chunks`(6),
  `seg_min_sec`(0.5), `seg_max_sec`(6.0)
- `/voice/event` 에 `listening`(5초마다, 소음 수준·주행 여부), `speech` 상태 추가

### `web/intent.py` — `parse_strict()` 추가
- 정규식: `N번(째)(자리|위치|장소)(으로|로|에|까지|쪽으로|쪽)` + 동사(`가` `이동` `출발` `데려` `안내`)
- 동사 뒤에 올 수 있는 말을 제한 → "1번 가방", "1번으로 가지 마" 는 무시
- 서로 다른 번호가 둘 이상 걸리면 무시, 등록 안 된 번호도 무시
- 테스트 21문장 (scratch) 통과. "1번으로 가 아니 2번으로 가" → 2번 (정정 발화로 처리, 의도대로)

### 웹 (`web/static/index.html`)
- '음성 명령' 칸: `🎙 상시 듣기 — "1번으로 가" · "멈춰"` + 소음 수준, 주행 중이면 "(주행 중: 멈춰만)"
- 지도 위: 말소리 감지(빨강) → 알아듣는 중(파랑)
- 무시한 말은 대화창엔 안 띄우고 기록 칸에 회색 `무시: "…"` 로만

### 실주행 결과 (오늘 로그)
| 항목 | 결과 |
|---|---|
| 이동 명령 | "1번으로 가." "3번으로 가자." "2번으로 가줘." "4번으로 가." "5번으로 가." 등 → 전부 출발·도착 |
| 정지 | "멈춰" → 정지 |
| 주행 중 다른 목적지 | "3번으로 가." → 무시 (주행 중) ✓ |

| 방 소음 RMS | 500 ~ 1300 (꽤 시끄러움) |

- 놓친 말: **"2번으로 가죠." "4번으로 가죠."** (동사 뒤 '죠' 미허용), "5번으로 와." ('와' 미포함) → 필요하면 `STRICT_VERBS` 에 추가
